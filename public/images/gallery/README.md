# Galería de Imágenes

Esta carpeta contiene las imágenes de la galería del café.

## Cómo agregar imágenes

1. Descarga las fotos de Google Maps del Café del Valle
2. Renombra las imágenes como:
   - `cafe-1.jpg` (o .png)
   - `cafe-2.jpg`
   - `cafe-3.jpg`
   - `cafe-4.jpg`
   - `cafe-5.jpg`
   - `cafe-6.jpg`
3. Colócalas en esta carpeta: `public/images/gallery/`

Las imágenes se mostrarán automáticamente en la galería del sitio web.

## Formatos soportados
- JPG/JPEG
- PNG
- WebP

## Tamaño recomendado
- Ancho: 800-1200px
- Relación de aspecto: 4:3 o 16:9
- Peso: máximo 500KB por imagen (optimizadas)
